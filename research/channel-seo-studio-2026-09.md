## Research findings (what actually matters for channel-level SEO, 2025-26)

1. **Channel description is the #1 channel-level search signal.** First ~150 chars show in search results + About preview — front-load the niche keywords there. Body should name entities YouTube can associate the channel with (Buffett, Theranos, FICO, etc.).
2. **Channel keywords are a minor but free signal** — they help YouTube classify the channel's niche (important at 0-6 subs when there's no behavioral data). 500-char limit.
3. **Trailer converts channel-page visitors** (30-90s best practice, hook in first seconds, who-it's-for + CTA). None of the 3 channels has one. Stopgap = best long-form doc.
4. **Playlists rank in search themselves** when named with searchable terms, and chain watch-time sessions (a ranking signal). Use searchable names, not cute names.
5. **Handles should be clean and brandable** — the -c7h/-p4y suffixes look spammy on share cards. Cleaner handles verified FREE on 2026-09-18: `@InvestorsCompassHQ`, `@TheMoneyRulebookHQ` (checked via API — no channel exists). Change now while channels are tiny; after growth a handle change breaks shared links.
6. **Consistency of niche > breadth.** All metadata should repeat the same core phrase per channel ("investing psychology" / "money rules" / "debt freedom") so YouTube locks the channel into one niche cluster.

Sources: [Increv channel trailer guide 2025](https://increv.co/academy/channel-trailer/), [Rev YouTube SEO 2025](https://www.rev.com/blog/youtube-seo-how-to-create-high-ranking-videos), [Vozo keyword best practices 2026](https://www.vozo.ai/blogs/youtube/youtube-keyword-best-practices), [Humble & Brag playlist SEO](https://humbleandbrag.com/blog/youtube-playlists), [DeanLong video SEO](https://www.deanlong.io/blog/best-practices-for-youtube-video-seo)
