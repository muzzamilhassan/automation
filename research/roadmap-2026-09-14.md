## PART 1 — FIX FIRST (bugs & risks found in this audit)

### 1.1 DOUBLE PRODUCTION — the biggest problem (evidence-backed)
The local automation "Quarry Pipeline — Morning Run (2pm PKT)" runs `run-all-channels.mjs`
(IC/MR/DFD) at 09:00 UTC, and the CI channel workflows produce the SAME channels at
09:35/10:05/10:35 UTC. The state file that prevents re-production never syncs between the
local machine and GitHub (the local run does not push).
**Evidence:** Investor's Compass had **6 reels go live on Sep 13** (should be 3);
DFD had 5 on Sep 12; counts on Sep 10 were 12-13 (backfill day, but same pattern).
**Fix:** pick ONE production master. Recommendation: CI (matches cloud-only goal).
The local automation becomes "topup only": git pull first, then API-based count check
(not the state file), and only produce what is actually missing.
Why: over-posting hurts retention signals, looks spammy, and burns quota for nothing.

### 1.2 Legacy 5-brand stack still in the repo
`content-machine.yml` (3 crons, disabled in UI but one click from re-enabling) +
`self-heal.yml` + `run-content-machine.mjs` still target the OLD 5 pages (Silent Wealth,
Strategic Silence, Eon Ventures, Reliq North, Boundaries Club). If it ever re-enables it
posts to old pages/channels and fights the new pipelines.
**Fix:** delete the workflow files + archive the old script. Keep git history.

### 1.3 FB photo posts silently broken
`yt-daily.mjs` uses `execFileSync` without importing it (line ~134). Every FB image-from-
video-frame post fails quietly. 1-line fix.

### 1.4 State file is a single point of conflict
`yt-mcp/schedule-state.json` is one JSON for all channels; two writers (CI + local) already
caused merge conflicts twice this week.
**Fix:** split to per-channel files (`yt-mcp/state/<slug>.json`) + keep the combined file
as generated output only, or auto-merge per-slug keys.

### 1.5 Music pool lock (waiting on you)
40-track approval menu built (6289257). One command locks the music engine to approved
tracks only. Pending your picks.

## PART 2 — ADD (ranked by money impact)

### 2.1 ⭐ Per-brand LONG-FORM finance documentaries (biggest revenue lever)
2026 data: finance is the highest-paying niche on YouTube — CPM $20-50, long-form RPM
$4-20 per 1,000 views. Shorts RPM is $0.01-0.07 — Shorts are a discovery funnel, not the
money. Long-form 8+ min enables mid-roll ads.
The engine already exists in the repo: `weekly-compilation.mjs` (daily compilation on the
main channel, proven), the LONGVIDEO documentary script engine (8-12 min, tested with a
10.5-min Paulson script), `yt-deepdive.mjs` (paused).
**Add:** 1-2 long-form videos per week per finance brand (IC/MR/DFD), built by the existing
engine. Example: 8-min "How Credit Cards Trap You" documentaries. At even 50K long-form
views/month in finance, that is $200-1,000/mo vs ~$5 from the same views on Shorts.
Cost: $0 (existing stack). Effort: wire + schedule + thumbnails.

### 2.2 Affiliate layer (the "money now" item from the monetization plan)
Pinned comment + description link slots exist on every upload already — they are just empty.
Add a per-niche affiliate link table (IC → investing offers, MR → money tools, DFD → debt
programs) rotated by upload. Networks: ClickBank/Digistore24, payouts via Payoneer → PK bank.
**Blocked on you:** Payoneer KYC + network signups (from the earlier monetization plan).

### 2.3 Telegram funnel per brand
Free bot API, no approval needed (unlike TikTok/Pinterest). Auto-post each Reel + poster to
a per-brand Telegram channel with the video link. Also doubles as a second notification
channel (NTFY is currently single-channel). Listed as "next" in the monetization roadmap.

### 2.4 Communities posts (now open to ALL channels)
The subscriber barrier was removed — every channel can post. Add 1 auto Community post/day
per channel: poll or quote card (posters already rendered for FB — reuse them). Free
engagement signal + keeps subscribers warm. YouTube is also expanding Communities in 2026.

### 2.5 Auto-dubbing + Hype (free reach, zero work)
- Auto-dubbing is now open to all creators (27+ languages) — verify it is ON for all 4
  channels in Studio settings. Free international views.
- Hype: all 4 channels qualify (<500K subs). Add "Hype this 🚀" to pinned comments.
- 3-minute Shorts are now standard — the recycler/shorts pipeline can experiment with
  60-90s formats (current renders ~50s) for more watch time per Short.

### 2.6 Controlled 15-channel expansion (careful)
12 dummy channels (1 slot/day each) exist in brands.json. Wiring them all at once = 12x
content + policy risk (inauthentic content rules). Recommendation: wire 2-3 at a time,
reuse the recycler pool + archive, keep per-channel format variety. Note: all channels sit
on ONE Google email — a single account problem kills everything; put new channels on 1-2
fresh accounts.
