# Spec + QA — `market-files` P1.5: the library art pass (Route B+C) (2026-11-11)

Source: docs/superpowers/specs/2026-11-11-market-files-p1.5-ai-art-spec.md
(owner decision: skip AI, build on free libraries + animated accents).
Plain English: replace the hand-drawn stick-figure look with REAL cartoon
art from free libraries — hand-drawn Open Peeps characters (CC0), glossy 3D
props like money bags and coins (CC0 3dicons), and animated accents — while
keeping every good layer (text, charts, boards, captions, voices, music).

## Requirements (EARS)

- R1: fetcher downloads from a curated DATA manifest into
  explainer/public/assets/market/, idempotent, loud on HTTP failures.
- R2: CREDITS manifest records source + license per asset; CC0 items need
  no attribution.
- R3: the recurring cast renders as Open Peeps (inline SVG), entrance/bob
  animation, per-mood treatment; stick-figure rig stays as fallback.
- R4: rooms keyed by the existing location field — no new beat fields.
- R5: stat/board beats float 3D props scaled by mood (crash → money-bag/
  thumb-down/fire falling; rally → rocket/star/trophy rising).
- R6: Lottie accents play through @remotion/lottie, fail-soft (missing file
  → skip, never fail the render).
- R7: other families render unchanged (default-inert).
- R8: Nov-5 episode re-rendered; storyboard stills reviewed vs reference;
  fresh demo for the owner's gate.
